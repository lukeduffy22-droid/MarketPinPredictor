## Copilot task tips (VS Code)

If Copilot chat tasks fail with an error code before finishing:

- Break requests into small, file-scoped tasks.
- Include explicit acceptance criteria (expected behavior, tests to run, and files in scope).
- Ask for a short plan first, then request implementation.
- Retry with a narrower prompt if a task fails mid-run.
