5) Correct GEX math and preserve sign (most likely your core bug)

If you compute “Total” using abs() or you treat puts the same as calls, you’ll get exactly what you’re seeing.

A robust convention (widely used for exposure, not P/L):

Compute unsigned exposure per strike (magnitude)

Compute net exposure with an explicit sign rule, consistently applied

Recommended implementation pattern:

call_gex = +gex(call)

put_gex = -gex(put) (this is the most common “net” convention used to create a meaningful call/put offset)

total_gex = abs(call_gex) + abs(put_gex)

net_gex = call_gex + put_gex

Guardrail:

If abs(net_gex) == total_gex for long stretches, your put side is missing or your sign rule is broken.

6) Snapshots must be time-consistent (stale spot + fresh options = fake signals)

If spot updates at 1 Hz but options update in bursts, you can accidentally combine mismatched times.

Action:

Define a snapshot as: one spot tick + one options chain within a max time skew (e.g., 250–500 ms).

If skew exceeds threshold, discard or resync.
