1. SKEW-ADJUSTED GAMMA (DIAGNOSTIC ONLY)
Goal

Detect directional pin bias caused by call/put IV skew.

What you are measuring

Not “better gamma” — skew pressure near spot.

Implementation
Step 1 — Capture skew per snapshot

In audit_snapshot.py, add:

def compute_skew_metrics(contracts, spot):
    atm_window = [c for c in contracts if abs(c.strike - spot) / spot < 0.01]

    call_ivs = [c.iv for c in atm_window if c.type == "call"]
    put_ivs = [c.iv for c in atm_window if c.type == "put"]

    if not call_ivs or not put_ivs:
        return None

    return {
        "call_iv_mean": sum(call_ivs) / len(call_ivs),
        "put_iv_mean": sum(put_ivs) / len(put_ivs),
        "skew": (sum(put_ivs) / len(put_ivs)) -
                (sum(call_ivs) / len(call_ivs))
    }

Step 2 — Store in audit snapshot
"skew_metrics": {
  "call_iv_mean": 0.184,
  "put_iv_mean": 0.201,
  "skew": 0.017
}

Step 3 — Do NOT adjust gamma with this

Use skew only in post-analysis.

Goal

def strike_distance_bucket(strike, spot):
    pct = abs(strike - spot) / spot
    if pct < 0.002: return "ATM"
    if pct < 0.01: return "NEAR"
    if pct < 0.03: return "MID"
    return "FAR"
