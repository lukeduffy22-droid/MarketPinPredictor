REQUIRED BEHAVIOR (NON-NEGOTIABLE)

When market_is_closed() is true:

Do not recompute gamma

Do not return an empty gamma state

Do not derive gamma from live memory

Always load the last valid audit snapshot

All gamma UI components must read from the same snapshot object used by the predictor, including:

Total GEX

Net GEX

Gamma walls (per strike)

Zero gamma level

Primary gamma pin

If no snapshot exists, explicitly mark gamma as unavailable.

Never silently render $0.0B

IMPLEMENTATION STEPS (EXACT)
Step 1 — Create a single snapshot loader

Add (or reuse) one canonical function:

def get_gamma_state(symbol):
    if market_is_closed():
        snapshot = load_last_valid_snapshot(symbol)
        if snapshot:
            return snapshot
        return None  # explicit unavailable
    else:
        return compute_live_gamma(symbol)


There must be no other gamma entry points used by the UI.

Step 2 — Update Gamma Exposure UI data source

Where the UI currently does something like:

gamma = compute_gamma(...)


or

gamma = current_gamma_state


Replace with:

gamma_snapshot = get_gamma_state(symbol)

Step 3 — Bind UI fields directly to snapshot values

Example mapping (adapt to your schema):

if gamma_snapshot is None:
    show_gamma_unavailable()
else:
    total_gex = gamma_snapshot["aggregate"]["total_gex"]
    net_gex = gamma_snapshot["aggregate"]["net_gex"]
    pin = gamma_snapshot["pin"]
    zero_gamma = gamma_snapshot["zero_gamma"]
    gamma_walls = gamma_snapshot["gamma_by_strike"]


Do not recompute or re-aggregate anything in the UI layer.

Step 4 — Add explicit UI state labeling

If snapshot is loaded:

Gamma (Frozen at 15:57:00 ET)


If snapshot missing:

Gamma unavailable — no frozen snapshot captured


Under no circumstance should the UI display $0.0B unless gamma is explicitly non-existent in the snapshot.

Step 5 — Remove silent fallback behavior

Search for and remove:

default empty gamma dicts

zero-filled placeholders

implicit recomputation when data missing

Replace all with explicit “unavailable” state.

If snapshot exists:

UI never shows $0.0B

If snapshot does not exist:

UI clearly states gamma is unavailable

Predictor and gamma UI use the same snapshot source
